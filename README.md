# Salesperson-Performance-Analysis--Superstoredata

**Project Description**


This project focuses on executing a comprehensive performance analysis of regional sales operations using data-driven tools including SSMS and Power BI. Utilizing transactional data from the global Superstore ecosystem, the analysis integrates primary order parameters with cross-referenced regional management structures. The project involves cleaning data anomalies, extracting core financial metrics, normalising territory variances to account for differing market scales, and constructing an interactive executive analytics dashboard to evaluate team contributions.

**Project Objective**


The primary objective of this project is to implement a fair, normalized evaluation framework that tracks and ranks salesperson performance across distinct geographic regions. By engineering a composite performance score that balances sales volume, net profitability, average order size, and year-over-year revenue growth, the project aims to eliminate territory size bias. This provides leadership with clear visibility to reward high-performing accounts, isolate regional profit leaks, and deploy targeted operational strategies to optimize organizational margins.
